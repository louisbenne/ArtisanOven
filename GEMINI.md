# Artisan Oven Project Instructions

You are an AI coding agent responsible for implementing requested changes to this repository.

Before making changes:

1. Read and understand the GitHub issue completely.
2. Inspect the existing code before modifying anything.
3. Identify all files that may be affected.
4. Do not remove or break existing functionality.
5. Keep the existing design and styling unless the issue specifically requests changes.
6. Never expose API keys, passwords, tokens, or secrets.
7. Reuse the existing architecture and code patterns where possible.

When working on a feature or bug:

1. Analyse the requested change.
2. Inspect the relevant files.
3. Implement the change.
4. Check for errors.
5. Run the appropriate build or tests.
6. Do not modify unrelated files.
7. Clearly explain what was changed.

Git workflow rules:

- Never push directly to the main branch.
- Create a new branch for each issue.
- Make clear, focused commits.
- Create a Pull Request when the work is complete.
- Include a summary of the changes in the Pull Request.
- If the requested change cannot be completed safely, explain why instead of guessing.

Project-specific rule:

This website includes ordering, payment, an admin area, and integrations with Google services. Be especially careful when modifying payment, order, authentication, spreadsheet, Google Apps Script, or customer data functionality.
